# Markdown Notes

A browser-based notes app with live Markdown preview. The Markdown parser is **written from scratch** (no libraries) and unit-tested.

- Create, search, edit and delete notes — stored in `localStorage`
- Live side-by-side preview; responsive layout; automatic dark mode
- Parser supports headings, bold/italic, inline & fenced code, links, images, lists, blockquotes, rules
- **Secure by default:** all HTML is escaped, and only `http(s)` links/images are rendered

## Run
Open `index.html` in a browser (no build step).

## Test
```bash
npm test
```
